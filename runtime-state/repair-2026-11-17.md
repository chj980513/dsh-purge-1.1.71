## 修复动作

### 1. `lib/core.js`（dsh-purge 包本体，已备份 `core.js.fix-*.bak`）
- `listLiangshenBootstrapFiles()` 增加 `minimal-prompt.mjs` 四个候选（web / web-fallback / desktop / `.agent-presets`）。
- 同一函数的 `push()` 判定由 `keepSurfaceFile(fp)`（只走 `allowTargetPath`）改为
  `allowTargetPath(fp) || allowTargetPathForAiBase(fp, _patchTargetAiBase || findAiBase())`，
  使 liangshen 装在桌面 profile 时，非桌面 surface（CLI / 独立 node）也能定位。
- `#28` 的 markers 增加 `markersAny: true` 与新标记 `// [dsh-purge] liangshen keep operator`
  （新版 `minimal-prompt.mjs` L810 天然带有该标记，说明放行早已生效）。

### 2. shipped preset 打 marker（#80）
- `@deepseek-ai/dsh-web-app/presets/minimal.patch.yml` 顶部加 `# [dsh-purge] minimal official toolset`
- `@deepseek-ai/dsh-sdk-minimal/cordis.patch.yml` 顶部同样加该 marker
- 备份后缀：`.prefixfix-*.bak`

### 3. 新建 unrestricted 预设（#76）
- `$DSH_HOME/.agent-presets/unrestricted/agent.cordis.yml` — agent 平面组合（persona + agent-instructions），
  persona 的 `prefix` 保留官方身份句原文且缩进拉到 14 空格以对齐 #76 pattern；
  apply 后已被清成 `prefix: ""`。
